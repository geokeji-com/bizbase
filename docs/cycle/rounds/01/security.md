保持已确认固定基础框架版本，记录继承风险；新增目录不调用 Git 克隆、PDF 渲染，不注册这些能力。普通目录用户无引用原生 CRUD，测试覆盖读取旁路。仅本地使用、无生产源凭据、无公网监听，不能由此推断其他 App 或管理账号已消除漏洞。

开放多人/公网前必须重新评估基础镜像升级、PDF 渲染隔离和源码 fork，并复跑完整验收。这项工作列入 backlog，不在本轮偷偷升级整套 ERP 框架。
