# 第 01 轮验收场景

依据已确认 D-007—D-009。S-01-R/D/O 对应私有真实样本；脚本从私有快照读取真实名称和 ID，公开测试使用明确的合成夹具，不把合成客户显示在正式入口。不存在上一轮软件回归。测试角色和账号均新建在隔离站点，不改现有 U-01。

身份约定：reader（人员）、client（独立机器消费者）明确获准 S-01-D；parent-reader 仅获准 S-01-R；no-grant 只有目录角色，无客户授权。名称是拟创建的测试身份，不是现有员工。

## 正常路径
<!-- section: normal -->

| 编号 | 操作 | 预期 |
|---|---|---|
| A1 | reader 登录“客户目录”，选择 S-01-D 的真实名称 | 返回 S-01-O 的真实 ID 与名称；显示 2026-11-02、历史快照及当前目录版本；分类缺失显示未知 |
| A2 | client 通过独立客户端读取同一客户 | 与 A1 的来源、客户/对象 ID、目录版本逐字段一致；客户端不直接读取私有快照 |
| A3 | 只配置读取角色和显式授权后再次执行 A1/A2 | 普通身份可完成路径，不依赖 Administrator 或 System Manager |
| A4 | 重放同摘要快照准备/启用，再核对引用和业务返回 | 不重复创建客户引用，不改变身份；审计结果可关联请求 |

## 空数据
<!-- section: empty -->

| 编号 | 操作 | 预期 |
|---|---|---|
| B1 | 仅在独立合成夹具中，为已授权客户提供零个对象 | 正常空结果，“无匹配对象”；不改变真实 S-01 数据或将其描述为零对象客户 |
| B2 | 在真实获准目录输入不会匹配的精确查询内容 | 空结果，不显示来源故障；支持恢复原查询读取 A1 |

## 失败与冲突
<!-- section: failure -->

| 编号 | 操作 | 预期 |
|---|---|---|
| C1 | 将验收实例指向缺失/损坏/摘要不符的独立测试快照 | 返回来源不可用；不解释为无客户，不回退旧数据；恢复有效配置后 A1 可重试成功 |
| C2 | 在合成版本 V1/V2 切换时并发读目录 | 每次返回只包含一个完整版本；记录版本；不存在半导入引用或混合响应 |
| C3 | 注入 Integration Request 写入失败后读取已授权客户 | 请求失败，不正常返回客户/对象；基础设施日志可定位且不含密钥 |
| C4 | 发出未知参数、伪造 actor/user 或无效客户标识 | 参数拒绝或与不存在一致的结果；不绕过当前认证身份，不触发其他来源读取 |

## 权限
<!-- section: permission -->

| 编号 | 操作 | 预期 |
|---|---|---|
| D1 | no-grant 调用目录列表；再直接请求已知 S-01-D | 列表拒绝；详情拒绝且不区分越权与不存在；零授权不能扩大为全部 |
| D2 | parent-reader 直接请求 S-01-D 及其对象 | 拒绝；S-01-R 授权不继承到 S-01-D |
| D3 | A1/A2 成功后提交撤销相应授权，各自使用已有会话/凭证发新请求 | 两入口均拒绝；生效边界为撤权提交后开始的新请求 |
| D4 | 分别提交账号停用、角色成员移除、目录 Role 停用，再发新请求 | 当前身份不能继续读取；逐一恢复并验证正确范围，防止缓存绕过 |
| D5 | 普通读者尝试原生资源列表、详情、frappe.client、链接搜索、导出；配置账号尝试分享客户引用 | 普通读者不能原生读取引用，分享被控制器拒绝；不能利用分享或第二入口读出范围外内容 |
| D6 | 检查成功/错误响应、页面网络和业务日志 | 仅批准字段；无范围外父 ID、税号、合同、成员、私有路径、凭据或原始整包数据 |
| D7 | 进入目录方法后分别产生成功、空结果、业务拒绝、来源失败 | 四类结果有持久业务审计，身份来自认证，记录请求 ID/结果/版本；拒绝后异常回滚不抹日志 |
| D8 | 无效凭据或停用账号在目录方法之前被框架拒绝 | 请求拒绝；通过框架日志核验定位，不要求该请求有 Integration Request |
| D9 | 普通账号读取业务审计、权限变更日志、私有源文件或配置 | 无管理权限不得读取日志和源文件；授权变更由配置管理员并有 Permission Log；记录实际日志保留配置 |

## 加载状态
<!-- section: loading -->

| 编号 | 操作 | 预期 |
|---|---|---|
| E1 | 在隔离测试注入目录响应延迟，再快速切换查询或客户 | 显示加载，旧请求不能覆盖较新的查询状态；失败和无权分别显示，不停留永久加载 |

## 提交与启用结果
<!-- section: result -->

| 编号 | 操作 | 预期 |
|---|---|---|
| F1 | 配置管理员启用经校验的本地快照或关闭目录功能 | 成功后新请求读取同一启用版本或明确不可用；失败不产生部分启用，日志可追溯 |
| F2 | 从干净隔离站点安装自研 App、导入最小样本并重建相同镜像 | 可重复运行 A1/A2；原 8080 站点及原卷不变化；新环境有备份/恢复或重建证据 |

独立客户端与内部页面都须经过同一业务接口。所有合成故障注入、身份和夹具只作用于隔离验收环境；原型可点击测试不能替代上述服务与权限验证。
