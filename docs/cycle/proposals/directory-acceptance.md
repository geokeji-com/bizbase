# 目录首版验收候选

2026-11-18；保留模型评审时的历史候选。最小模型已按 D-007—D-009 确认，当前权威入口为[第 01 轮正式验收](../rounds/01/acceptance.md)，预算见[一页纸](../rounds/01/one-pager.md)，执行和验证映射见[readback](../rounds/01/readback.md)。本文件不再作为待转入的任务。

输入 S-01 是私有真实样本；以下测试身份及合成边界样例只存在于隔离测试/原型，不是生产人员或客户。使用验收账号，不用 Administrator 证明权限正确。

| 场景 | 具体输入与动作 | 预期结果 |
|---|---|---|
| 真实成功路径 | 测试人员取得 S-01 交付客户授权，打开内部“客户目录”，选择该客户 | 返回 S-01 优化对象和原始来源 ID；明确显示 2026-11-02 数据日期和历史快照属性 |
| 第二个消费者 | 专用机器账号获同一客户授权，通过独立客户端查询 | 与内部页面的客户/对象复合身份和目录版本一致；并非读取另一份手工维护主档 |
| 零授权 | 有目录角色但没有客户授权的账号调用列表及详情 | 列表拒绝读取；详情对范围外与不存在采用一致拒绝；零授权不能变成全量可见 |
| 不继承层级 | 只授予 S-01 登记客户，直接请求交付客户对象 | 拒绝，不因同集团、上下级或合同关系放行 |
| 来源不决定权限 | 输入已知真实来源客户/对象 ID，或伪造 actor/user 字段 | 不能扩大当前身份的可读范围；不支持的身份参数拒绝 |
| 撤权 | 已读取成功后提交撤销，再分别从页面与客户端发新请求 | 两个入口均拒绝；清浏览器缓存不是生效条件 |
| 账号/角色变更 | 提交停用账号或撤销目录角色后，再使用已有凭证发新请求 | 拒绝；普通页面会话与 API 凭证分别验证 |
| 原生旁路 | 普通读者尝试原生资源列表、详情、搜索、导出；配置侧尝试分享客户引用 | 无原生读取权限；分享被禁止；不从第二入口取得范围外引用 |
| 准确空态 | 在独立合成测试夹具中，为获准客户提供零对象列表 | 显示无匹配对象；不伪造真实客户的“零对象”事实 |
| 加载与故障 | 注入延迟、快照缺失或摘要不符 | 先显示加载；失败显示来源不可用，保留已知来源 ID，不显示“没有客户” |
| 字段最小化 | 检查成功、失败、列表、详情响应和浏览器网络 | 无范围外父 ID、税号、成员、合同、私有路径或凭证；原始分类未知不改为品牌/产品 |
| 版本一致 | 两个不同的合成版本切换时发起并行读取 | 单次响应属于一个完整版本，不混版本；同一摘要导入不重复引用 |
| 业务审计 | 已通过框架认证、进入目录方法后，分别执行成功、业务拒绝、空结果、来源失败和审计存储失败 | 前四类具有可关联的持久结果记录；最后一类不放行读取且可定位基础设施错误；无密钥或原始载荷 |
| 认证层日志 | 使用无效凭证或已停用账号，使请求在进入目录方法前被框架拒绝 | 请求被拒绝，按框架日志核验状态与定位能力；不要求不存在的目录方法执行记录，也不宣称有业务 Integration Request |

允许/拒绝是待建立的本地验收授权，不能引用 2026-11-02 历史源系统的浏览器验证替代。真实样本成功与合成边界测试分开计数；全是空态/错误态不能通过首版验收。

首版计为 D-004 的本地测试软件增量，须实际安装、可访问、完成上述必要路径并有 release 记录；本文件及静态原型不计软件发布。实时源、完整服务和生产权限仍各有独立证据要求。
