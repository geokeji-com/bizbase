### 调研时的建议

- 继续使用现有 Frappe、ERPNext、CRM，没有因“要建数据底座”而必须立即补装的官方 App。
- Insights 在有真实经营分析问题、数据口径明确后优先试评；已有运营手册先继续使用，Wiki 降为明确文档迁移需求后引入。Builder、Learning、Helpdesk 分别按官网维护、培训考核、正式工单需求选装。版本与依赖证据见分项复核。
- 共享数据优先覆盖主体/品牌/服务关系、品牌事实、内容版本、问题集版本、采样证据及指标定义。每种事实明确维护方，上层应用可以保持不同界面和分析方法。
- 各厂商同名指标未必同义；原始证据、分母、采样条件和计算版本必须可追溯。内容发布、获引、提及、访问与成交分别记录。
- 业务介绍与手册阅读已经完成；下一步按整体方案选择真实服务链，核对旧 ID、唯一维护方、指标口径与授权，再实现最小接入闭环。本文中的早期调研不直接作为正式业务表定义。
