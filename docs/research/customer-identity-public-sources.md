# 公开名称核验：北京移山科技有限公司、唯品会

核验日期：2026-11-21。以下分别核对两个名称；行政许可、企业自述、平台条款和上市公司年报各自证明的事项不同。

## 北京移山科技有限公司

| 核对项 | 结论与证据 |
| --- | --- |
| 主体名称与代码 | 北京市广播电视局的[2025 年行政许可决定](https://gdj.beijing.gov.cn/xzxkxxgsNEW/2025/202508/t20250829_4187387.html)将「行政相对人名称」列为**北京移山科技有限公司**，「行政相对人代码」列为 `91110105MA01U1P03M`，法定代表人列为房志武。[2023 年同局公示](https://gdj.beijing.gov.cn/xzxkxxgsNEW/2023/202310/t20231012_3276669.html)中的名称、代码和法定代表人与之相符。 |
| 许可记录 | [2025 年决定](https://gdj.beijing.gov.cn/xzxkxxgsNEW/2025/202508/t20250829_4187387.html)批准延续广播电视节目制作经营许可证，许可生效日期为 2025-08-29，公示所列有效期限为 2027-08-29。该期限针对这项行政许可，并非营业执照期限。 |
| 对外名称与网站 | [移山科技官网常见问题](https://www.geokeji.com/faq)自述「移山科技，即北京移山科技有限公司」，使用英文品牌 **YISHAN TECHNOLOGY**，并将 GEO（生成式引擎优化）列为业务方向。这是企业对品牌及业务的说明，不是英文法人名称或登记经营范围的证明。 |

**未核实：** 本次访问[国家企业信用信息公示系统](https://www.gsxt.gov.cn/)返回 HTTP 521，未取得企业登记详情页。上述代码保留行政许可公示的字段名称；当前登记状态、现任法定代表人及注册地址未通过登记机关独立核实。

## 唯品会

| 名称层级 | 可确认的身份 | 一手依据 |
| --- | --- | --- |
| 品牌／平台 | **唯品会（Vipshop）**是平台名称；`vip.com` 是集团年报列明的平台网站。 | [唯品会基本功能隐私政策](https://www.vip.com/privacy)；[Vipshop Holdings Limited 2025 财年 Form 20-F](https://www.sec.gov/Archives/edgar/data/1529192/000110465926044015/vips-20251231x20f.htm)对 Vipshop 移动应用和 `vip.com` 网站的说明。 |
| 上市主体 | **Vipshop Holdings Limited** 注册于开曼群岛，纽交所交易代码为 **VIPS**。 | [Form 20-F 封面](https://www.sec.gov/Archives/edgar/data/1529192/000110465926044015/vips-20251231x20f.htm)。 |
| 境内平台运营者 | **广州唯品会电子商务有限公司**是平台明确列名的运营者。 | [基本功能隐私政策](https://www.vip.com/privacy)（2026-06-18 生效）写明：「唯品会平台运营者为广州唯品会电子商务有限公司」。[服务条款](https://h5rsc.vip.com/h5rscSupportClause/h5rscSupportClause/index.html)（2026-06-24 生效）第 2.2 条的经营者定义还包括其关联方。 |

**不能据此认定：**「唯品会」不是足以唯一确定法律主体的全称。仅凭品牌名不能确认某笔交易的销售方、开票方或合同相对方，须以对应订单、发票或合同为准。[服务条款第 2.2 条](https://h5rsc.vip.com/h5rscSupportClause/h5rscSupportClause/index.html)也不支持将所有平台业务一概归于一家境内公司。
