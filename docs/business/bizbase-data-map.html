按表结构拆分，442 张为普通实体表、367 张为子表、6 张为 Frappe 特殊表。站点有 890 个逻辑 DocType，其中 81 个 Single 或 Virtual 没有独立同名表，其余 809 个可逐张对应。六张特殊表负责认证、搜索、用户设置、编号、会话及单例存储。

在 Frappe，DocType 定义一种记录的字段、表单和权限。常规 DocType 和子 DocType 各自落表，子表行通过 parent、parenttype、parentfield 归属主记录。Single 设置共用 tabSingles，虚拟 DocType 由代码提供数据。一个工作区也可以只是官方 Workspace 表里的一条配置。

一个客户可以有多项服务

客户和合同分别回答“交易对象是谁”和“签了什么”。服务还要登记被服务组织、优化标的和参与人员。相同问句可以被多项服务采用，每项服务有自己的监测计划、应采记录和授权。

读图和分析口径

客户、合同均可被多项服务引用。服务绑定计划，计划生成应采记录，每条可关联一个执行任务。多条兼容的应采记录可以共用任务。任务每重试一次就增加一条尝试，最终最多接纳一个结果。分析按服务从应采记录取证，固定竞品版本和分析方法版本。报告通过 GEO Report Sample 保留纳入的应采记录和分析引用。

从一次应采到一条报告结论

例如，计划要求采十次，只采到八次。分析需要保留那两条缺口，再按选定口径决定拒答是否进入分母。查看旧报告时，可以查到当时采用的样本和口径。

同一份报告可以在两个域名发布不同版本

授权记录 File Share Grant 说明谁委托了终端。File Share Operation 用于核对员工写操作及重复请求。File Share Access Log 记录收件人访问时的域名、版本和结果。
