安装文件分享助手

把提示词交给可以在你电脑上运行命令的 AI Agent。安装完成后，你在浏览器里用自己的员工身份授权。

发给我的 Agent

首次登录和绑定

  1. 打开 CLI 给出的浏览器页面，选择「通过移山 ID 登录」，按页面指引完成飞书员工扫码。
  2. 若系统提示尚未绑定，将提示中的移山 UID 交给管理员。管理员核对身份，在移山 ID 绑定选择该员工本人的 BizBase 账号并启用。没有员工账号时，由管理员先建立启用的系统用户。
  3. 绑定完成后重新运行登录，核对终端名称和八位确认码，再点击「确认授权」。密码和授权码只在公司登录页面输入。

管理已授权终端

在文件分享的终端授权打开一条记录，点击「禁用此终端」。员工可管理自己的授权，系统管理员可按员工管理全部授权。重新使用已禁用的终端需要再次登录授权。

要停用员工的移山 ID 登录，由管理员在移山 ID 绑定停用相应绑定。要停用整个 BizBase 账号，在用户中停用该系统用户。

Agent 安装步骤
  1. 取本页 URL 的源地址作为 SITE。使用本机 Python 3.9 或以上版本，macOS/Linux 使用 python3，Windows 可用 py -3。在新建的临时目录从同一源下载下载清单和客户端包。使用 HTTPS，本机回环预览可用 HTTP。下载过程中仅使用原站点，不跟随跨站跳转。
  2. 核对清单的 filename 等于 bizbase.pyz，文件的 SHA-256 等于清单的 sha256。校验成功后运行 python3 -I /绝对路径/bizbase.pyz install --site SITE。已有安装也通过同一命令更新。
  3. 读取安装输出 JSON 中的 command 参数数组，用它启动 --json whoami。已经是所需账号即可完成。需要登录时，用同一数组启动 login 并保持进程运行，把它显示的授权 URL 和确认码原样交给员工。员工在浏览器确认后，执行 --json whoami，告诉员工账号和技能安装位置。安装提示词只授权安装和身份检查。
